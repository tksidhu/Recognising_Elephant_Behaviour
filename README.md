# Recognising_Elephant_Behaviour
includes data and code for main analysis and models: 
intercept-only generalised linear mixed models to test whether participants recognised valence and behaviour at above-chance
GLMM_valence: Correct Valence (0/1) ~ Participant Group + Stimulus Type + Stimulus Valence/Behaviour Category + (1 | Participant ID) + (1 | Event ID) + (1 | Trial Number)
GLMM_behaviour: Correct Behaviour (0/1) ~ Participant Group + Stimulus Type + Stimulus Valence/Behaviour Category + (1 | Participant ID) + (1 | Event ID) + (1 | Trial Number)
